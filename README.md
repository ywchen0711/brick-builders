# 積木建造家：空蕩島 · Brick Builders: Empty Isle

像《勇者鬥惡龍 創世小玩家 2》那樣的積木建造 RPG：在一座什麼都沒有的荒島上醒來，手上只有一把鎚子，旁邊站著愛打架的夥伴黑牙。把島上的方塊敲碎變成材料，在工作台做出家具，用牆圍出房間，村民就會搬來住。

**線上玩：** https://ywchen0711.github.io/brick-builders/

## 怎麼玩

| | 鍵盤滑鼠 | 手把 |
|---|---|---|
| 移動 / 跑 | WASD / 按住 Shift | 左搖桿 |
| 跳 | 空白鍵 | A |
| 敲擊（挖方塊、打怪、收成） | 左鍵 或 J（按住連敲） | X / RT |
| 放置（方塊、家具、種子、吃東西） | 右鍵 或 K | LT |
| 選快捷欄 | 滾輪、1～8 | LB / RB |
| 使用 / 對話 | E | B |
| 隨身製作（工作台） | C | Start |
| 背包 | I | Y |

**手機、平板**：左邊拖曳是搖桿，右邊拖曳轉視角；右下角有「敲（按住連敲）、跳、放、用、做、包」按鈕，快捷欄點一下就能選。

畫面正中央的十字是準星：白框是會被敲到的方塊，淡藍色的方塊是會放下去的位置。

## 島上有什麼

- **材料**：敲草地和泥土得到土塊，樹幹是木材，樹葉是樹枝，岩石是石頭；東北的山上有銅礦、鐵礦和煤；池塘邊有黏土；草叢和樹葉有時候會掉種子。硬的方塊要敲好幾下，做出銅鎚、鐵鎚會更快。
- **製作**：先按 C 做出工作台放在地上，在工作台按 E 就能做木板、木門、稻草床、火把、桌椅、石磚、田地、茅草……基地升級後會解鎖大鍋、木箱、銅鎚、白牆、盆栽、鐵鎚、燈籠、屋瓦、紅磚、地毯、書架。在大鍋可以用兩顆高麗菜煮蔬菜湯。
- **房間**：用方塊圍出**兩格高**的牆、再裝一扇**木門**，就是一間房間（屋頂可有可無）。裡面放什麼決定它是什麼房間：

| 房間 | 需要 | 幸福愛心 |
|---|---|---|
| 溫馨臥室 | 床、燈籠、盆栽 | ♥30 |
| 廚房 | 大鍋、桌子 | ♥25 |
| 書房 | 書架、桌子、椅子 | ♥25 |
| 餐廳 | 桌子、兩張椅子 | ♥20 |
| 臥室 | 床 | ♥12 |
| 工作室 | 工作台 | ♥12 |
| 儲藏室 | 木箱 | ♥10 |
| 空房間 | （什麼都沒有） | ♥4 |

- **基地等級**：收集幸福愛心讓基地從 Lv1 升到 Lv5，每升一級解鎖新配方、搬來一位村民：農夫阿花、木匠老木、廚師胖廚、小孩小石。他們會拜託你事情（種 5 顆高麗菜、蓋餐廳、蓋廚房、打倒 10 隻史萊姆），心情好的時候頭上會冒出愛心，走過去就能收集。晚上他們會回到床上睡覺。
- **種田**：用「田地」對著草地或泥土按放置就會翻成田，再把種子撒在田上。高麗菜會照真實時間慢慢長大（關掉遊戲也會長），長好了敲一下就能收成。
- **史萊姆**：晚上會從野外冒出來，跳著撞你；牠們進不了房間。黑牙會自己衝上去打。在床上按 E 可以一覺睡到天亮。
- 一開始有一串教學目標（右上角）帶你從挖土一路蓋到村莊。遊戲會自動存檔。


## 敵人與頭目

| 敵人 | 出沒 | 掉落 |
|---|---|---|
| 史萊姆 / 紅史萊姆 | 晚上的草原 | 黏液、種子 |
| 蝙蝠 | 晚上，從空中俯衝 | 蝙蝠翼 |
| 哥布林 | 西邊的森林，白天也有 | 獸皮、銅礦 |
| 骷髏兵 | 晚上的東北礦山，又硬又痛 | 骨頭、鐵礦 |

- **哥布林王**：守在森林深處的哥布林營地（木樁圍牆、帳篷、營火）。走近就會醒來：棍子砸地（地上先出現紅色扇形）、往前衝撞（先出現紅色直線），血剩一半會叫來手下。打倒得到「哥布林戰旗」。
- **史萊姆王**：基地升到 Lv3 之後的第一個晚上會來襲擊基地：跳到你頭上重壓（地上先出現紅圈，落地有衝擊波要跳過）、生氣時滾過來撞人，還會叫小史萊姆。打倒得到「史萊姆王冠」。
- 頭目出現時畫面上方有血條；打倒頭目再加 ♥60。

## 武器與防具

敲方塊用鎚子，打架用武器：敵人靠近時手上會自動換成你裝備的武器。在背包（I）點武器或防具就能裝備。

| 武器 | 攻擊 | 配方 | | 防具 | 防禦 | 配方 |
|---|---|---|---|---|---|---|
| 木棒 | 2 | 木材×2 | | 布衣 | 1 | 樹枝×3、黏液×2 |
| 銅劍 | 3 | 銅礦×3、木材 | | 皮甲 | 2 | 獸皮×4 |
| 鐵劍 | 5 | 鐵礦×3、煤 | | 鐵甲 | 3 | 鐵礦×5、獸皮×2 |
| 勇者之劍 | 8 | 史萊姆王冠、鐵礦×2、蝙蝠翼×2 | | 王者之鎧 | 4 | 哥布林戰旗、鐵礦×3、骨頭×3 |

防禦會從每次受到的傷害裡扣掉（至少還是會扣 1）。

## 怎麼做的

沿用《武林積木：龍門江湖》的積木引擎：

- `js/voxel.js`：方塊世界（32×32 的區塊、只畫看得到的面、凸點），加了銅礦、鐵礦、煤、田地、茅草、紅磚
- `js/worldgen.js`：192×192 的空蕩島（海灘、草原、西邊的森林、東北的礦山、池塘、舊村莊的殘石）
- `js/items.js`：物品、掉落、配方、房間、基地等級、村民與任務、教學目標
- `js/furniture.js`：家具、作物、史萊姆的積木模型
- `js/mobs.js`：敵人（史萊姆、蝙蝠、哥布林、骷髏兵）與頭目（史萊姆王、哥布林王）：出沒的地方和時間、追擊、地上的紅色預警、衝擊波
- `js/game.js`：移動與鏡頭（越肩視角）、準星瞄準（逐格射線）、敲擊與放置、房間判定（從門往內做洪水填充，牆要兩格高）、製作選單、村民、史萊姆、存檔（只存你改過的方塊）
- 人物用 `js/brick/minifig.js` 的積木小人
